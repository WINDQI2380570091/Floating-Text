# Floating Text（悬浮文字）

**语言：** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [繁體中文（香港）](README.zh-HK.md)

在世界中的任意位置放置可编辑的悬浮文字，像贴纸、公告牌或装饰标语一样。右键方块面或空气放置文字，右键文字可编辑内容、颜色、大小、位置和旋转。文字使用游戏原生字体渲染，支持存档和多人同步。

- Minecraft 1.20.1 · Forge 47.x（已在 47.4.10 测试）· Java 17
- 无依赖、无 Mixin、无核心模组 API
- 支持 10 种语言

---

## 玩法功能

- **放置文字** — 右键方块面，文字紧贴表面放置，自动居中在面中心；右键空气，文字悬浮在面前 3 格。放在天花板和地面上时，文字会自动横放。
- **随时编辑** — 右键文字打开编辑界面：内容（最多 100 字）、颜色（8 种内置颜色）、大小（0.15 ~ 10）、X/Y/Z 偏移（-1 ~ 1）、旋转（0 ~ 360°）。放置后编辑界面会自动弹出。
- **原生字体渲染** — 使用 Minecraft 自带的字体渲染，任何角度都可见（双面渲染）、全亮显示、无阴影，并带深度偏移，紧贴方块不会闪烁。
- **数据持久** — 文字保存在世界存档中，退出重进游戏依然存在。
- **多人同步** — 修改即时同步给所有玩家；只有创建者可以编辑文字。
- **零依赖** — 无核心修改、无 Mixin、无第三方库。可与其他任何 1.20.1 Forge 模组（如机械动力 Create）共存。多人联机时服务端也需安装。

## 技术实现

- **基于实体实现** — 每条文字是一个自定义 `Entity`（不是方块、不是 BlockEntity），所以文字可以悬浮在空中，也可以贴在任何方块面上。实体没有任何每 tick 逻辑，游戏会自动剔除屏幕外的实体，性能开销接近静态实体。
- **数据同步** — 所有可编辑字段放在 `SynchedEntityData` 中（改动自动同步）。在此基础上，每次保存后服务端还会通过自定义的 S2C 全量同步包（`SyncFloatingTextPacket`）把完整状态广播给所有玩家，绕开原版"只有不同于默认值才同步"的机制——偏移 0.00、白色这类默认值也一定能到达客户端。
- **网络** — 使用 Forge `SimpleChannel`（`floatingtext:main`，协议版本 2）。数据包：
  - `UpdateFloatingTextPacket`（C2S，编辑/删除）：载荷是 `CompoundTag`，按键名读写，免疫字段顺序错位。
  - `SyncFloatingTextPacket`（S2C，保存后全量广播）。
  - `T72AVBoomPacket`（C2S，彩蛋）。
- **服务端安全校验** — 创建者权限校验、同维度校验、8 格距离校验；文字截断到 100 个 Unicode 码点（不会切断 emoji）；所有数值做边界限制（大小 0.15~10、偏移 ±1、旋转 0~360），拒绝 NaN/Infinity。
- **存档** — 通过 `saveAdditional` / `readAdditionalSaveData` 读写 NBT；读取时所有数值再次限制，存档损坏也不会出现巨型文字。
- **渲染** — `FontRenderer.drawInBatch`，Y 负缩放翻转（字体是 GUI 坐标、Y 向下，世界坐标 Y 向上）；双面渲染（背面转 180°）；`POLYGON_OFFSET` 显示模式（紧贴方块无 Z 冲突）；全亮光照、无背景、无阴影。
- **放置逻辑** — 位置固定在所点方块面中心 + 沿法线外移 0.01 格；朝向吸附到最近的 90°；放在地板/天花板上时通过 xRot ±90° 让文字横放。
- **客户端自动弹窗** — 放置后等实体的同步数据到达（600 毫秒延迟），校验创建者、且当前没有打开其他界面时才自动弹出编辑界面；用以实体对象为键的 `WeakHashMap` 防止重复弹窗和内存泄漏。
- **兼容性** — 无 Mixin、无原版类修改、无第三方依赖、不使用核心模组 API（Fabric API / NeoForge API）。所有注册使用 `floatingtext` 命名空间。与 Create、优化类模组（Embeddium、Rubidium 等）及其他任何 1.20.1 Forge 模组共存。

## 构建

- 需要 JDK 17
- `gradlew build`（Windows：`gradlew.bat build`）
- 产物：`build/libs/floatingtext-1.0.0.jar`（已 reobf，可安装）。`-sources` 后缀的 jar 不能安装。
- 安装：把 jar 复制进 `mods` 文件夹（多人联机时服务端和客户端都要装）。

## 支持语言

简体中文、繁体中文（港/台）、英语、日语、韩语、法语、俄语、西班牙语、阿拉伯语。

## 彩蛋

创造模式标签页里有一个叫 **T-72AV** 的物品。使用它什么都不会发生……除非你的游戏语言是阿拉伯语。
