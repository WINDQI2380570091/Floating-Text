# Floating Text（懸浮文字）

**語言：** [English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [繁體中文（香港）](README.zh-HK.md)

在世界中的任意位置放置可編輯的懸浮文字，像貼紙、公告牌或裝飾標語一樣。右鍵方塊面或空氣放置文字，右鍵文字可編輯內容、顏色、大小、位置和旋轉。文字使用遊戲原生字體渲染，支援存檔和多人同步。

- Minecraft 1.20.1 · Forge 47.x（已在 47.4.10 測試）· Java 17
- 無依賴、無 Mixin、無核心模組 API
- 支援 10 種語言

---

## 玩法功能

- **放置文字** — 右鍵方塊面，文字緊貼表面放置，自動居中在面中心；右鍵空氣，文字懸浮在面前 3 格。放在天花板和地面上時，文字會自動橫放。
- **隨時編輯** — 右鍵文字開啟編輯介面：內容（最多 100 字）、顏色（8 種內建顏色）、大小（0.15 ~ 10）、X/Y/Z 偏移（-1 ~ 1）、旋轉（0 ~ 360°）。放置後編輯介面會自動彈出。
- **原生字體渲染** — 使用 Minecraft 自帶的字體渲染，任何角度都可見（雙面渲染）、全亮顯示、無陰影，並帶深度偏移，緊貼方塊不會閃爍。
- **資料持久** — 文字儲存在世界存檔中，退出重進遊戲依然存在。
- **多人同步** — 修改即時同步給所有玩家；只有建立者可以編輯文字。
- **零依賴** — 無核心修改、無 Mixin、無第三方函式庫。可與其他任何 1.20.1 Forge 模組（如機械動力 Create）共存。多人連線時伺服端也需安裝。

## 技術實作

- **基於實體實作** — 每條文字是一個自訂 `Entity`（不是方塊、不是 BlockEntity），所以文字可以懸浮在空中，也可以貼在任何方塊面上。實體沒有任何每 tick 邏輯，遊戲會自動剔除螢幕外的實體，效能開銷接近靜態實體。
- **資料同步** — 所有可編輯欄位放在 `SynchedEntityData` 中（改動自動同步）。在此基礎上，每次儲存後伺服端還會透過自訂的 S2C 全量同步封包（`SyncFloatingTextPacket`）把完整狀態廣播給所有玩家，繞開原版「只有不同於預設值才同步」的機制——偏移 0.00、白色這類預設值也一定能到達用戶端。
- **網路** — 使用 Forge `SimpleChannel`（`floatingtext:main`，協定版本 2）。資料封包：
  - `UpdateFloatingTextPacket`（C2S，編輯/刪除）：酬載是 `CompoundTag`，按鍵名讀寫，免疫欄位順序錯位。
  - `SyncFloatingTextPacket`（S2C，儲存後全量廣播）。
  - `T72AVBoomPacket`（C2S，彩蛋）。
- **伺服端安全驗證** — 建立者權限驗證、同維度驗證、8 格距離驗證；文字截斷到 100 個 Unicode 碼點（不會切斷 emoji）；所有數值做邊界限制（大小 0.15~10、偏移 ±1、旋轉 0~360），拒絕 NaN/Infinity。
- **存檔** — 透過 `saveAdditional` / `readAdditionalSaveData` 讀寫 NBT；讀取時所有數值再次限制，存檔損壞也不會出現巨型文字。
- **渲染** — `FontRenderer.drawInBatch`，Y 負縮放翻轉（字體是 GUI 座標、Y 向下，世界座標 Y 向上）；雙面渲染（背面轉 180°）；`POLYGON_OFFSET` 顯示模式（緊貼方塊無 Z 衝突）；全亮光照、無背景、無陰影。
- **放置邏輯** — 位置固定在所點方塊面中心 + 沿法線外移 0.01 格；朝向吸附到最近的 90°；放在地板/天花板上時透過 xRot ±90° 讓文字橫放。
- **用戶端自動彈窗** — 放置後等實體的同步資料到達（600 毫秒延遲），驗證建立者、且目前沒有開啟其他介面時才自動彈出編輯介面；用以實體物件為鍵的 `WeakHashMap` 防止重複彈窗和記憶體洩漏。
- **相容性** — 無 Mixin、無原版類別修改、無第三方依賴、不使用核心模組 API（Fabric API / NeoForge API）。所有註冊使用 `floatingtext` 命名空間。與 Create、最佳化類模組（Embeddium、Rubidium 等）及其他任何 1.20.1 Forge 模組共存。

## 構建

- 需要 JDK 17
- `gradlew build`（Windows：`gradlew.bat build`）
- 產物：`build/libs/floatingtext-1.0.0.jar`（已 reobf，可安裝）。`-sources` 後綴的 jar 不能安裝。
- 安裝：把 jar 複製進 `mods` 資料夾（多人連線時伺服端和用戶端都要裝）。

## 支援語言

簡體中文、繁體中文（港/台）、英語、日語、韓語、法語、俄語、西班牙語、阿拉伯語。

## 彩蛋

創造模式標籤頁裡有一個叫 **T-72AV** 的物品。使用它什麼都不會發生……除非你的遊戲語言是阿拉伯語。
